## Learned User Preferences

- Wire every new user-visible string through `window.t()` and add matching English and Chinese keys in `src/i18n.js`; do not ship hardcoded UI copy (user corrected missing i18n on history delete confirmation).
- Match the user's language in replies when they write in Chinese.
- Session branch UX: allow branching only from assistant/agent messages, not user messages; prefer per-message actions over duplicating the same flow in the bridge command menu.
- Message actions (copy as Markdown, branch) should sit at the bottom-right of bubbles and use accent styling so they stay visible.
- Quick Bar UX: support multi-turn and choosing send-to-current vs new session; keep the overlay result pane on the current turn only (never flash older active-session history); keep "no project" default cwd aligned with the main window; pin the reply area to the bottom while streaming (pause if the user scrolls up); omit Esc from the shortcut hint bar (Esc still closes/aborts).
- Settings (tweaks) panel: open anchored to the bottom-left gear control, not the bottom-right; dismiss when clicking outside the panel.
- Image upload for non-vision models: warn only, never block send or file picker — omp reads images via external tools even without native vision; do not reintroduce `composer.warn.uploadAnyway`.
- After an in-app update restart, prefer a short grace period and a “starting agent” state over an immediate `agent.processNotRunning` banner when omp is only slow to appear (usually transient).

## Learned Workspace Facts

- PiDesk i18n lives in `src/i18n.js` (`window.t`); it loads before Babel design scripts per `src/index.html` script order.
- Saved omp sessions on disk are under `~/.omp/agent/sessions/<session_dir>/` with `.jsonl` files (shared per project directory); omp RPC always persists turns there — no Tweaks autosave switch (the old toggle was vestigial UI only). `delete_saved_session` removes only that specific session `.jsonl` file (and cleans up the parent directory if empty) after canonicalizing paths under the sessions root, preventing accidental loss of other sessions in the same project folder.
- Session fork/merge alignment: UI `state.messages` is head-trimmed (169 cap) and omp stores `toolResult` rows as `"message"` events, so never map UI indexes to the session file by position or count. `app/branch-session.js` resolves a bubble to an omp entry id (tail-aligned, strict) for `copy_session_file(untilEntryId)` (Rust: `src-tauri/src/session_copy.rs`, errors on unknown id, keeps the cut turn's tool results); `app/message-merge.js` aligns `get_messages` onto the local list. On a failed match, refuse with a `branch.fail.*` warning — never fall back to a full copy.
- Agent Hub (`src/design/hub/`) replaced the old Agent Activity card in the ambient rail (Compact/Tree/Summary via `hubMode`, `hubAgents`, `hubTaskId`, `hubHistory` in `live.js`). Peer sessions: `src/peer-session.js` as `window.PeerSessionBridge` (**not** `PeerSession` — React component in `design/chrome/ambient-rail.jsx`), init from `live.js`.
- `AssistantBubble` renders `msg.blocks` only; client-side assistant notices must use `src/app/notice-bubble.js` (`window.NoticeBubble.make`). omp start/exit failures surface only via `AgentErrorBanner` / `state.agentError`, not chat bubbles.
- @ file references: pure helpers in `app/file-mention.js` (`window.FileMention`); composer chips in `design/composer-file-chips.jsx` + pub/sub in `app/composer-files.js`; send `@relativePath` in `prompt.message` (omp auto-reads via file-mentions); `@` autocomplete and file-tree “引用该文件” attach chips; user bubbles render path-like `@` tokens as chips.
- Quick Bar is a separate Tauri webview (`src/quick-bar.html`) that does **not** load `live.js`; it communicates with the main window via Tauri `emitTo` events (`quickbar://submit`, `quickbar://delta`, `quickbar://done`). Host-side relay is `src/app/quickbar-host.js` (Markdown HTML for the overlay is rendered there with the main window's `marked`/hljs pipeline, then styled in Quick Bar via `md-content`). System tray and global shortcut (`CmdOrCtrl+Shift+Space` default, persisted to `quick-bar-shortcut.json` in app config dir) are in `src-tauri/src/tray.rs` and `src-tauri/src/shortcut.rs`; the Quick Bar window is pre-created hidden at startup via `quick_bar::warm_up` so the first tray/hotkey click does not race WebView2 attach. Window uses `.shadow(false)` plus a 24px transparent gutter (`GUTTER` in `quick_bar.rs`, same value as `body` padding in `quick-bar.html`) so CSS draws the card shadow (fixes macOS grey rectangular edges on transparent windows). Height sync is `use-auto-height.jsx` (reports `.qb-root` content height only; Rust adds gutter via `window_size`); streaming scroll pin is `use-stick-bottom.jsx` — load both before `quick-bar.jsx`. Never cap `.qb-root` with a viewport-based `max-height` tied to window size (deadlocks growth with `set_quick_bar_height`).
- "No project" omp sessions (main default tab, New Standalone, Quick Bar new session) pin cwd with `agent::workspace::default_cwd(&app)` to `<app_local_data_dir>/workspace` (created on demand, falls back to the executable's directory) — never inherit ambient process CWD (fragile across `cargo run` / install / terminal launch). Rust saved-session scan (`mark_standalone`) sets `is_standalone: true` for that workspace, the legacy exe dir (`workspace::legacy_exe_dir`) and the old cwd patterns; `live.js` `resumeSession` must pass empty `cwd` for standalone (`is_standalone` or `RecentProjects.isStandalonePath`) so history resume stays project-less (no file tree/git watch) and spawn re-pins default cwd instead of a stale debug-dir path.
- Code Review drawer: React UI in `src/design/review/`; pure diff/split/store logic in `src/review/` (`ReviewDiff`, `ReviewSplit`, etc.) — follow `src/index.html` script order when adding review modules. Enabled only when `src-tauri/src/review/repo.rs` reports a git repo (`git rev-parse`); non-git projects have no review until a non-git baseline snapshot path exists.
- macOS close-to-tray: `src-tauri/src/main_window.rs` centralizes show/hide — hiding the main window calls `set_dock_visibility(false)`; showing (tray, single-instance relaunch, or `RunEvent::Reopen` from a Dock click) restores the icon via `set_dock_visibility(true)`. Tray and `lib.rs` close handler route through this module instead of ad-hoc `win.hide()`/`win.show()`.
- omp RPC quirks: 18.x `get_state` omits `thinkingLevel` and `cycle_thinking_level` returns null — PiDesk cycles client-side `off → low → medium → high` via `set_thinking_level` (never `"auto"`). Compact responses include `tokensBefore` but not `tokensAfter`; snapshot pre-compact from `contextUsage` and back-fill on the next `get_state` via `_compactBackfillId` in `live.js`. `spawn.rs` `rpc_mode()` must not cache inconclusive `omp --help` probes (binary temporarily missing) in `OnceLock` — retry on the next spawn.
- Developer reference is project-root `manual.md` (English); READMEs link to it and `CLAUDE.md`. Frontend unit tests live under `test/` (Node 20 `node:test`, zero npm test deps); `test/helpers/shim.mjs` loads IIFE scripts with `globalThis.window = globalThis`; run `npm run test:js` (on PowerShell the `test/*.test.mjs` glob may not expand — use `node --test test/`). In-app updates: `tauri-plugin-updater` via `src-tauri/src/update.rs` + `app/updater.js` / `use-updater.jsx`; `restart_app` stops all omp children; signed builds need `TAURI_SIGNING_PRIVATE_KEY` (see `MANUAL.md`). Updater writes `update-restart.flag` under app local data before relaunch; next startup consumes it in `src-tauri/src/agent/grace.rs` and uses `start_session_with_grace` (~30s spawn retries) while `live.js` polls `is_session_starting` via `app/agent-startup-wait.js` instead of flashing `agent.processNotRunning`.
